# Portfolio — Joersinio Silva

## Présentation

Bienvenue sur mon portfolio personnel !

Je suis étudiant en informatique et j'ai créé ce site pour présenter mon parcours, mes compétences et les projets que je réalise au cours de mes études.

## Objectifs du projet

- Présenter mon parcours et mes compétences.
- Mettre en valeur mes projets informatiques.
- Développer mes compétences en développement web.
- Créer une interface moderne, claire et responsive.

## Technologies utilisées

- **HTML5** : structure des pages.
- **CSS3** : mise en forme et animations.
- **JavaScript** : interactions et fonctionnalités dynamiques.

## Fonctionnalités

- Présentation personnelle.
- Section dédiée aux compétences.
- Galerie de projets.
- Fenêtres pop-up présentant les projets.
- Formulaire de contact.

## Installation et utilisation

1. Clonez le dépôt :

   git clone URL_DU_DEPOT

2. Accédez au dossier du projet :

   cd NOM_DU_DOSSIER

3. Ouvrez le fichier HTML principal dans votre navigateur ou utilisez l'extension Live Server de Visual Studio Code.
